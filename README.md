# Olá, eu sou o Bruno 👋

Corretor de imóveis migrando para tecnologia — 
unindo experiência real de mercado imobiliário com automação e IA aplicada.

## 🚀 O que eu construo

Sou fundador da **ArIA Automações**, agência de automação com IA voltada 
para corretores e pequenas imobiliárias no Brasil. No dia a dia, projeto e 
implemento agentes de IA que atendem, qualificam e fazem follow-up de leads 
via WhatsApp — do primeiro contato até o agendamento de visita.

Também mantenho o **Descomplicasa**, plataforma de conteúdo imobiliário.

## 🛠️ Stack principal

- **Orquestração/Automação:** n8n (self-hosted em VPS)
- **IA/LLM:** Groq (Llama 3.3 70B), engenharia de prompt para agentes SDR
- **Backend/Dados:** Supabase (Postgres + pgvector + RLS), Redis
- **Integrações:** Evolution API (WhatsApp), Meta Ads (CAPI, Conversions API)
- **Workspace/Ops:** Notion como hub operacional

## 💡 Projetos em destaque

- **Agente SDR multi-etapas** — arquitetura multi-agente (Acolhimento, Base 
  de Imóveis, Simulação, Documentação, Agenda de Visita) com follow-up 
  automatizado de D+1 a D+15
- **Funil Meta Ads → WhatsApp 100% automatizado** — Click-to-WhatsApp + n8n 
  + CAPI, com distribuição de leads round-robin
- **ArIA QA** — pipeline de testes automatizados para agentes de IA 
  (simulador de cliente + juiz avaliador via Groq)
- **Backup Sentinela** — rotina noturna de backup Postgres com validação de 
  integridade e monitoramento via Healthchecks.io
